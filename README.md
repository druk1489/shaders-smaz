# SMAZ Studio — Silent Engine UI

Логика и гуишка разделены на отдельные файлы (каждый — независимый chunk,
чтобы не упираться в лимит 200 локальных переменных). Запуск через лоадер.

## Запуск (лоадер)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/druk1489/shaders-smaz/main/loader.lua"))()
```

## Файлы
| Файл | Что делает |
|---|---|
| `loader.lua` | тянет и запускает остальные файлы по очереди |
| `atmosphere_v9.lua` | ядро атмосферы + API `SMAZ_ATMOS` |
| `tornado_v10.lua` | торнадо `SMAZ_TORNADO` |
| `rain_v11.lua` | дождь `SMAZ_RAIN` |
| `lightning_v12.lua` | молнии `SMAZ_LIGHTNING` |
| `reflections_v1.lua` | отражения `SMAZ_REFL` |
| `presets_v1.lua` | пресеты `SMAZ_PRESETS` |
| `control_panel.lua` | гуишка Silent Engine UI |

Лоадер грузит логику в порядке списка, потом панель. Если файл не
загрузился — выведет `[SMAZ LOADER] файл НЕ загрузился: ...` в консоль,
остальные продолжают работать.

## Хоткеи
- **Shift+P** — фрикам (WASD движение, E/Q вверх/вниз, удерживай ПКМ + мышь — обзор, колесо — зум, Shift — медленно, Ctrl — быстро)
- **RightControl** — показать/скрыть панель (клавиша переназначается в НАСТРОЙКИ)
- **X** — спрятать ВСЕ гуи (все ScreenGui скрипта + core UI), ещё раз X — показать обратно

## Что стало с настройками
- При входе **ничего не применяется**: blur / bloom / sunrays / sharpen / погода /
  молнии / торнадо / дождь / отражения — выключены по умолчанию.
- Вкладка **НАСТРОЙКИ → Сохранение**: кнопки «Сохранить настройки» /
  «Загрузить настройки» (файл `smaз_settings_<PlaceId>.json` через writefile),
  всё сохраняется вручную.
- Вкладка **ПРЕСЕТЫ** — 20 готовых пресетов освещения (Realistic, Cinematic,
  NeonNight, Horror, Foggy, FPS и т.д.).

## Вкладки панели
- **СЦЕНА**: СВЕТ, ПОСТ FX, КАМЕРА (FOV, Фрикам, дыхание перспективы)
- **АТМОСФЕРА**: АТМОС (облака/светила/цикл), ПОГОДА (+ авто-цикл)
- **МОДУЛИ**: ЭФФЕКТЫ (молнии/торнадо/дождь/отражения), ПРЕСЕТЫ, НАСТРОЙКИ
  (хоткей панели, сохранение, инфо)

## Отражения: как это устроено
- **Планарные клоны** (`reflections_v1`, МОДУЛИ → ОТРАЖЕНИЯ): зеркалят парты
  под плоскостью пола. Честное ограничение движка: под **непрозрачным** полом
  клоны скрыты глубиной — видно их только на стекле/воде. Там же: радиус,
  прозрачность, клонирование персонажа.
- **Shine / PBR-лайт** (там же, ниже): Future + env-карты + `Reflectance`
  скайбокса на партах + зеркальная вода. Виден везде, почти бесплатен,
  всё обратимо (оригиналы возвращаются при выкл). Для обычных полов — это он.
- Настоящих SSR/ray-traced отражений в Роблоксе нет и скриптом их не сделать
  (нужен доступ к рендер-таргету) — выше максимум из доступного.

## Фикс «лучи не вырубаются»
Панель раньше плодила безымянные дубликаты эффектов (`getOrCreate` без Name,
тумблер писал только в атмосферу) — теперь дубликаты именованы и стартуют
выключенными, тумблер гасит и свой эффект, а ядро каждый кадр душит чужие
SunRays/Bloom пока соответствующий флаг выкл.
